# Shopify App Store listing in Urdu

This is the Urdu translation of Akeed's Shopify App Store listing, ready to paste into the Partner Dashboard. It is not published by this repository: adding a translated listing is a manual step in the Partner Dashboard (see [How to add it](#how-to-add-it)).

## Before you add it

- **Add Urdu only when the app can be used in Urdu.** Shopify allows a language in the listing's Languages section only if merchants can use the app's interface in it (App Store requirement 4.3.2). The Urdu interface is the `ur` locale of the frontend. Check it yourself in the embedded app first, and have a native Urdu speaker read it.
- **Urdu is an interface language only.** Customers still get their WhatsApp messages in Arabic or English. The listing below says so in App details, and must keep saying so. Do not add Urdu to any text about customer messages.
- **The English and Arabic listings stay as they are.** Nothing below changes them.
- **Check the source text.** The Urdu fields follow the content of the live English listing. Compare each one with the English field in the Partner Dashboard before pasting, in case the English text has changed.

## Not translated

- **Screenshots and the feature image** still show the English or Arabic interface. Replace them with Urdu screenshots when you have them, and write their alt text in Urdu.
- **Demo store, support email, privacy policy and FAQ links** are the same for every language.

## How to add it

1. Open the Partner Dashboard and go to **App distribution > All apps > Akeed > Distribution > Manage listing**.
2. On the primary listing, add **Urdu** to the Languages section.
3. Choose **Add translated listing** and pick **Urdu**.
4. Paste each field from [Listing fields](#listing-fields) and [App details](#app-details-479-of-500-characters). Check the character counter under each field.
5. Paste the Urdu text of every plan from [Pricing plans](#pricing-plans).
6. Enter the search terms.
7. Save, then submit the listing if the dashboard asks for a review.
8. Open `https://apps.shopify.com/akeed?locale=ur` in a private window and check that your text is shown, not Shopify's automatic translation.

To take it back, open the Urdu listing and choose **More actions > Delete listing**, and remove Urdu from the Languages section.
